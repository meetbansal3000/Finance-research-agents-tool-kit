## Step 4: Security Audit

### 1. Unescaped User Input in `unsafe_allow_html`
- **Locations**:
  - `tools/meridian_desk_ui.py:374`: `st.markdown(f"... {ra.get('message', '')} ...", unsafe_allow_html=True)`
  - `tools/meridian_desk_ui.py:515`: `st.markdown(f"**{p_sym}**<br>...{p_id} • {p_asset} • ... {p_venue}...", unsafe_allow_html=True)`
  - `tools/meridian_desk_ui.py:517`: `st.markdown(f"... {p.get('strategy_type', 'Standard')} ...", unsafe_allow_html=True)`
  - `dashboard.py:1087, 1090`: `st.markdown(f"<meta http-equiv='refresh' content='0; url={tv_web_url}'>", unsafe_allow_html=True)`
  - `dashboard.py:4074`: `st.markdown(f'<a href="{url}" target="_blank">...</a>', unsafe_allow_html=True)`
- **Vulnerability**: If alert messages, custom order IDs, strategy descriptions, or URL parameters contain untrusted or malicious HTML/JavaScript tags (e.g. `<script>`, `onload=`), Streamlit renders them as executable script in the browser.
- **Fix**: Apply `html.escape()` to all dynamic string variables before string interpolation.

### 2. API Keys Written to `os.environ`
- **Location**: `dashboard.py:2443`
  ```python
  if custom_key:
      st.session_state["gemini_custom_key"] = custom_key
      os.environ["GEMINI_API_KEY"] = custom_key
  ```
- **Vulnerability**: Mutating `os.environ` in a Streamlit application alters process-wide global state. In multi-user or shared server deployments, one user's key becomes the default key for all other concurrent sessions, and the secret is exposed to any subprocess spawned by the server.
- **Fix**: Remove `os.environ["GEMINI_API_KEY"] = custom_key`. Keep the key scoped strictly to `st.session_state["gemini_custom_key"]` and pass it directly to `genai.configure(api_key=...)` or agent constructors.

### 3. Hardcoded Secrets
- **Scan Command**: `git grep -E "(AIza[0-9A-Za-z_-]{35}|sk-[a-zA-Z0-9]{20,}|ghp_[a-zA-Z0-9]{20,})"`
- **Result**: No live cloud provider API keys (OpenAI, Gemini, GitHub) were found committed to git.
- **Defect**: Static HMAC fallback secret exists:
  - `tools/ledger.py:19`: `DEFAULT_HMAC_KEY = b"antigravity-finance-hmac-key-v1"`
  - `tools/ledger.py:34`: fallback return when `LEDGER_HMAC_STRICT == "0"`
  - `.env.example:10`: `LEDGER_HMAC_KEY=antigravity-finance-hmac-key-v1`
- **Fix**: Delete `DEFAULT_HMAC_KEY`. In `get_hmac_key()`, raise `RuntimeError` if no key is configured or generate an ephemeral random session key (`secrets.token_bytes(32)`).
